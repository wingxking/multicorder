Set up Multicorder

The extension captures tab audio; the Multicorder app on your Mac records, transcribes and summarises it. Audio only goes to the app on this Mac (127.0.0.1).

  1. Install and open Multicorder for Mac. It registers itself with Chrome, Edge and Brave on first launch.
  2. Developers running from source: start mcd serve and run mcd install-host --extension-id <this extension's id>.
  3. Come back to a tab with audio and click the Multicorder icon (or press Alt+Shift+R).

Recording other people? Tell them first. Some places require everyone's consent.
